# V44 — Head / body-part group scale handles

This update improves the selected body-part box so small parts like the head are easier to scale.

## Added / improved
- When you select the **head** (or any body part), a **visible box** appears around that selected part.
- That box now has better **corner scale handles** so you can drag from the corners and make the selected part bigger or smaller.
- The selected part box has:
  - move by dragging the box
  - scale by dragging the 4 corner handles
  - rotate by dragging the rotate handles
  - flip horizontally
- Small parts now get a little extra **padding + minimum box size** so the handles are easy to catch.
- In full-stage camera mode, the part box also gets a minimum size so the head box remains usable.

## Result
- Head selection is easier to see
- Head scaling is easier to control
- Selected group handles are more usable on tiny parts
