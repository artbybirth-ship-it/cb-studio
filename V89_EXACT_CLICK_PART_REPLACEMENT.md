# V89 — Exact Click-Part Replacement

- Single click on a visible body part selects that exact part.
- Head click shows only head suggestions.
- Head replacement uses a head-only transparent crop; neck/shoulders are excluded.
- Left/right hand suggestions use hand-only crops.
- Left/right leg suggestions use lower-leg/foot-only crops.
- Replacement click keeps that exact part selected.
- Removed the old automatic head-down offset so replacement stays in the original part slot.
- Source erase bounds were tightened so replacing the head does not erase the neck.
