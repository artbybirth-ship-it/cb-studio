# V58 — Shortcuts + light fade + full body visible

This update adds keyboard shortcuts for part editing and reduces the body fade while editing a selected part.

## Fixed / added
- After head replacement, the full body remains visible.
- When you edit a selected part, the other body parts now fade only lightly instead of becoming too dim.
- Arrow keys now move the selected body part.
- Shift + Arrow moves the selected body part faster (10px step).
- Cmd/Ctrl + `+` scales the selected body part up.
- Cmd/Ctrl + `-` scales the selected body part down.
- Esc exits selected body-part edit mode.

## Result
- Replace head → full body visible.
- Double-click replaced head → edit that part.
- Use arrow keys to move it.
- Use Shift + Arrow for larger movement.
- Use Cmd/Ctrl + plus/minus to scale it.
- The rest of the body stays visible with only a mild fade.
